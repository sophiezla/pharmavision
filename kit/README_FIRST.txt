PharmaChecked GPU kit  (__NAME__, commit __COMMIT__)
==================================================

PRIVATE: this kit contains permission-restricted images. Keep it on your own computers.
Do not upload it, share it, or put it in a cloud folder.

What to do
----------
1. Unzip this folder anywhere with at least __DISK__ GB free (for example C:\pharmakit).
2. Double-click 1_SETUP.bat. Only the first time; it needs internet and takes 10-30 minutes.
3. Double-click 2_RUN.bat. It runs everything and, at the end, creates a file named
   RESULTS_....zip in this folder. Copy that file back to the laptop.

If the computer restarts or the window is closed, just double-click 2_RUN.bat again:
finished work is kept and it continues where it stopped.

What 2_RUN.bat runs: __JOBS__ jobs from __JOBFILE__ (about __ESTIMATE__).
