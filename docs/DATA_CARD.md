## Preprocessing

1. **Inventory** (`results/tables/raw_inventory.md`): formats, modes, sizes, unreadable files,
   exact duplicates within and across sources.
2. **Normalization** (`pharmachecked.data.normalize`): EXIF orientation, ICC to sRGB,
   transparency composited on white, lossless PNG. The image id is the first 16 hex characters of
   the SHA-256 of the original file. Byte-identical files collapse to one image; identical files
   with conflicting labels are dropped (none occurred).
3. **Near-duplicate groups** (`results/tables/dedup_summary.md`): 64-bit pHash, union-find over
   pairs at Hamming distance ≤ 10 (ADR-006). Groups never cross partitions.
4. **Splits** (`splits/v1.json`, `results/tables/split_balance.md`): 15% of groups form the locked
   test set (stratified by label). The other 85% is split into 5 outer `StratifiedGroupKFold` folds
   with inner train/val/cal of 75/12.5/12.5%, seed 42.

## Known limitations

- **Acquisition differs by class in the development pool** (ADR-005). Counterfeit images are
  PNG with an alpha channel, authentic images small JPEGs; resolution and file size also separate
  the classes (`results/tables/raw_inventory.md`). A model can exploit these cues, so every
  experiment also reports external-set performance.
- **The development pool is small**, so validation and calibration partitions are about 55 images
  per fold and confidence intervals are wide.
- **The external sets are single-class.** Mendeley is authentic-only and Split E counterfeit-only,
  so each supports specificity or recall respectively, not AUROC.
- **Labels are taken from the sources' folders or records** and have not been audited (PLAN E3
  audits the development pool).
