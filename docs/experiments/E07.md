# E07 · Cross-dataset transfer (one direction, ADR-022)

Written before the experiment runs (PLAN 4.3); the Results section is added afterwards.

## Question

How well does each comparison model, trained on the whole Kaggle development pool, separate
authentic from counterfeit images that come from other sources?

## Hypothesis

Cross-source AUROC is well below in-source AUROC for every model, because in-source the classes
are also separated by acquisition (ADR-005). No hypothesis about the model ranking.

## Design (ADR-022)

- Source A (training) = the whole development pool of data v2 (Kaggle), split once into
  train / val / cal (75 / 12.5 / 12.5, grouped by `group_id`, stratified by label, seed 42).
- Source B (test) = the external sets pooled: `mendeley_split_c` + `mendeley_split_d`
  (authentic) and `split_e_harvested` + `split_e_regulatory` (counterfeit).
- The reverse direction is not run: B has one class per source and training on external images
  would break ADR-005.
- The locked test set is not touched (Rule 2).

## Models and runs

The five comparison models (ADR-021), seeds 0, 1, 2: 15 runs.

## Metrics

- In-source: pooled OOF AUROC of the model's within-source 5-fold `p4ref` runs (reference).
- Cross-source: AUROC on source B (seed-averaged probabilities per image, 95% stratified
  bootstrap CI, 2,000 resamples); Mendeley specificity and Split E recall at the val-selected
  threshold.
- Drop = in-source − cross-source AUROC with a bootstrap CI (independent resampling of the two
  image sets).

## Planned tables and figures

- `results/tables/e07_transfer.{csv,md}`: model, in-source AUROC, cross-source AUROC, drop
  (CI), Mendeley specificity, Split E recall.

## Findings

- The hypothesis holds: cross-source AUROC is below in-source AUROC for every model, and every
  drop CI excludes 0 (smallest drop: EfficientNetV2-S, 0.139 [0.108, 0.172]).
- The ranking changes completely between sources. In-source, ConvNeXt and Swin are best
  (1.000); cross-source, the final model (0.860) and DINOv2 (0.847) are well ahead, and Swin
  (0.538, CI includes 0.5) is the weakest, behind the handcrafted model (0.605).
- At the val-selected threshold DINOv2 is very conservative on the external images (Mendeley
  specificity 0.953, Split E recall 0.269); the final model is more balanced (0.835 / 0.600).
- Caveat (ADR-005): Mendeley is all authentic and Split E all counterfeit, so the
  cross-source AUROC also measures how well a model separates these two acquisition sources; it
  is not a clean estimate of counterfeit detection on new data.
