## 4. Anomalies, failed runs, open problems

1. **No failed runs in the kit.** 334 runs + 75 E9 evaluations, 0 failures, 0 dirty (`results/pipeline/e09_status.json`, stage logs).
2. **PatchCore bug, fixed.** Both kit PatchCore runs had AUROC 0.500 [0.500, 0.500]: the map `prob = 1 - exp(-score)` rounded to exactly 1.0 for every image, because PatchCore's raw anomaly scores are large. The raw score was not saved, so the runs could not be repaired. Fixed in 9ca2980 (`score / (1 + score)`, with a regression test) and both fits rerun on the laptop CPU (same config and data; CPU instead of the RTX 5060). The kit runs, and one rerun that was marked `_dirty` because docs were being edited when it started, were moved to `results/scratch/superseded/` (git-ignored, not deleted). The prototype verifier was not affected.
3. **E7: large drop for every model, ranking reversed.** Cross-source AUROC 0.538–0.860 against in-source 0.976–1.000; every drop CI excludes 0. The final model transfers best (0.860 [0.826, 0.891]); Swin, joint-best in-source, is lowest (0.538, CI includes 0.5). This supports ADR-020 from a direction it was not chosen on. Caveat (ADR-005): Mendeley is all authentic and Split E all counterfeit, so this AUROC also separates acquisition sources.
4. **E9: the severity grid did not find a failure point.** The four deep models keep AUROC ≥ 0.961 under every condition; the final model's quality limit is severity 5 for all nine corruptions. Only the handcrafted model falls below 0.85 (Gaussian noise and perspective warp at severity 5). The 0.85 limit (ADR-023) therefore carries no information for the final model at these severities. The hypothesis that blur and JPEG hurt most is not supported.
5. **E8: unseen-type loss is real for some models.** DINOv2 (blister 0.918 vs 1.000), EfficientNetV2-S (blister 0.954 vs 1.000) and the handcrafted model (packaging 0.879 vs 0.964) lose clearly; ConvNeXt and Swin lose ≤ 0.006. The prototype verifier (no counterfeit images seen) reaches 0.944 / 0.970, above PatchCore (0.907 / 0.940). Seen vs unseen is descriptive (different training sets, no pre-registered test).
6. **E6: calibration degrades before AUROC.** At 10%, pooled ECE is up to 0.158 (EfficientNetV2-S) while AUROC stays ≥ 0.972 for the deep models. Small statistical quirk: for a few arms the pooled ECE point estimate lies just outside its bootstrap CI (e.g. `convnext-tiny/ft-frac25` 0.016 [0.017, 0.030]); binned ECE is biased upwards in bootstrap resamples. The aggregator is unchanged from earlier phases.
7. **E08.md wording corrected.** It said `e08_open_set.md` regenerates the qualifying-type counts; it does not (the `images` column confirms 229 / 175). Noted in E08.md.
