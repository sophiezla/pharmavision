## 4. Anomalies, failed runs, open problems

1. **Classes are separable by acquisition in the development pool** (ADR-005): counterfeit images are PNG with an alpha channel, authentic images small JPEGs. Accepted as is, with an external-set block in every experiment.
2. **Packaging type is associated with the label**: `both` (25 authentic, 0 counterfeit) and `other` (145 vs 2) are almost all authentic. This matters for the E4 router and for E8; see decision 4.
3. **CLIP zero-shot packaging pre-labels were close to useless** (agreement 30.5%, kappa 0.047): CLIP calls most blister images "packaging". The human labels are what the pipeline uses.
4. **Two `not_a_drug` images** (one per class) stay in v1 and are flagged for the E3 label audit (Sophie, 2026-10-10).
5. **Places365 now requires a signed access form**, so Open Images V7 scenes (CC BY 2.0, author recorded per image) replaced it.
6. **Operational:**
    - Open Images downloads were reset by the server once (retries added).
    - One OOD build was stopped by Claude Code because the laptop was critically low on memory (free RAM was 0.5–2 GB during the session); it was re-run with smaller batches.
    - The local-only `CLAUDE.md` was garbled by a PowerShell encoding round-trip and restored byte-exactly.
    - The manifest validator let a missing fold pass; a test caught it and it was fixed.
7. DTD contributed 249 images, not 250, because two sampled files were identical.

## 6. Proposed plan for Phase 2 (details for approval before execution)

- **Shared infrastructure, built and tested on the laptop:**
    - 2.1 trainer: AdamW, cosine schedule with warm-up, AMP, early stopping on val AUROC, resume support;
    - 2.2 metrics and statistics: bootstrap CI, DeLong, McNemar, Holm, plus the ADR-005 external block;
    - 2.3 model registry: timm/open_clip wrappers and handcrafted features with LR/XGBoost;
    - 2.4 figure utilities;
    - per-experiment job lists and a data bundle for the GPU PC.
- **E1 baseline ladder** (2.5–2.8):
    - Runs: 2 handcrafted × 15, the small CNN × 15, 8 full fine-tuning configurations × 15 = 120 GPU runs, 3 linear probes × 15, zero-shot CLIP, and the VLM (decision 2).
    - Optuna (≤ 30 trials on fold 0) for the best model of each tier.
- **E2 adaptation strategies** for the two best backbones; **E3 label audit** (including the two `not_a_drug` images).
- **GPU-hour estimate:** not yet possible honestly. CLAUDE.md §12 requires the fold-0/seed-0 time measured on the machine that runs it. The laptop CPU benchmark (`results/tables/bench_laptop-cpu.md`) puts the 8 fine-tuning configurations at about 181 CPU-hours at the 30-epoch maximum (331 training and 55 validation images per run, 15 runs each). The GPU PC's benchmark plus one fold-0 run per model will turn that into a real estimate before any batch is launched.
